# ZHunter PRO — Agent Rules

## IMPORTANT: Credits are Limited — Follow These Rules Strictly

### Rule 1: ALWAYS Make a Plan First
- Before making ANY change to code, STOP and show a clear plan to the user
- The plan must explain: what will change, which files, and why
- Wait for the user to say "yes" or "proceed" before writing any code
- NEVER start coding immediately after a request

### Rule 2: NEVER Run Unnecessary Tool Calls
- Do NOT open files you don't need
- Do NOT run multiple searches when one is enough
- Do NOT check the same file twice
- If you already know the answer, say it directly — don't use tools to confirm

### Rule 3: Read Before You Write
- Before editing any file, read only the specific section you need to change
- Do NOT read the whole file if you only need 20 lines
- Use grep/search to find the exact location first, then view only that section

### Rule 4: No Guessing — Ask First
- If the user's request is unclear, ASK one simple question before doing anything
- Do NOT assume and start working

### Rule 5: Minimal Changes Only
- Change ONLY what is needed — nothing more
- Do NOT refactor or "improve" other parts of the code unless asked
- Do NOT add extra features that were not requested

### Rule 6: Report What You Did — Briefly
- After making changes, give a SHORT summary (2-3 lines max)
- Do NOT write long explanations of what the code does
